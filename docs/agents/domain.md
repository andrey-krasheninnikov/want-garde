к задаче решения в `docs/adr/`. Использовать термины словаря.
Отсутствующие документы не блокируют работу и не требуют пустых заготовок.

Before exploration, read the existing root `GLOSSARY.md` and relevant
decisions in `docs/adr/`. Use the glossary vocabulary.

Identify conflicts with accepted ADRs explicitly.
